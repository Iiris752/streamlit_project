Tämä projekti on Streamlit-sovellus, jolla visualisoidaan Tilastokeskuksen kuntakohtaisia hotellitilastoja.

- Datan haku suoraan PxWeb CSV -rajapinnasta
- Valitun kunnan datan tarkastelu taulukkomuodossa
- Trendit valitulle mittarille
- Vuosittaiset yöpymiset
- Kotimaiset vs. ulkomaiset yöpymiset (taulukko + viivakaavio)
- Kahden kunnan vertailu samassa kuvaajassa
- Mahdollisuus ladata vertailudata CSV-tiedostona

Teknologiat:
- Python
- Streamlit
- Pandas
- Matplotlib / Seaborn
PxWeb API (Tilastokeskus)
